# 🚀 AssetFlow - 반응형 개인 자산관리 및 AI 리밸런싱 코칭 웹앱

Firebase Realtime Database를 백엔드로 활용하여 PC와 모바일(아이폰 PWA/Safari) 간 실시간 양방향 동기화되는 스마트 개인 자산관리 웹 애플리케이션입니다.

---

## 🌟 주요 기능

### 1. 실시간 양방향 데이터 동기화 (Firebase RTDB)
- PC 데스크톱에서 값을 수정하면 접속 중인 아이폰 및 태블릿 화면에 **새로고침 없이 실시간 즉시 반영**됩니다 (`onValue` 리스너).
- `/assets`: 실시간 자산 등록/수정/삭제
- `/history`: 자산 변동 히스토리 스냅샷 (일별 누적 데이터 자동 관리)

### 2. 상단 대시보드 요약 지표
- **총 평가액**, **총 투자 원금**, **총 평가 손익(KRW)**, **총 누적 수익률(%)**을 실시간 계산하여 카드 형태로 제공합니다.
- 한국형(상승 빨강/하락 파랑) 및 글로벌형(상승 초록/하락 빨강) 색상 테마를 자유롭게 설정할 수 있습니다.

### 3. 자산 변동 추이 차트 (Asset Trend Graph)
- **Recharts AreaChart** 기반의 총 평가액 vs 총 투자 원금 이중 영역 차트.
- 원금 대비 자산 격차(초과 수익/손실)를 시각적으로 한눈에 확인.
- 기간 필터 버튼: `[1주일]`, `[1개월]`, `[3개월]`, `[6개월]`, `[전체]`.
- 원클릭 **"현재 시점 스냅샷 저장"** 및 초기 사용자를 위한 **"시뮬레이션 히스토리 생성"** 기능 지원.

### 4. 포트폴리오 비중 차트 (Allocation)
- 카테고리별(현금/예금, 국내주식, 해외주식, 가상자산, 기타) 비중을 **Recharts 도넛 차트(PieChart)**로 시각화.
- 카테고리별 평가액, 비중(%), 손익률 및 직관적인 컬러 시스템 적용.

### 5. 자산 목록 및 반응형 인터랙션
- **PC 데스크톱**: 행(Row) **더블클릭** 시 상세 정보 및 수정 모달 오픈 (우측 편집 버튼도 제공).
- **아이폰 / 모바일**: 터치 최적화 카드 레이아웃 지원, 단일 탭으로 모달 오픈.
- 카테고리별 탭 필터링, 검색창, 평가액순/수익률순/이름순 다중 정렬 지원.
- 전체 자산 대비 비중 프로그레스 게이지 표시.

### 6. 자산 등록 & 수정 모달
- 5대 카테고리 원클릭 선택.
- 투자 원금 및 평가액 입력 시 **한국 원화 3자리 콤마 자동 포맷** & 모바일 **`inputMode="numeric"`** 숫자 키패드 지원.
- 편리한 퀵 버튼 (`+10만`, `+100만`, `+1000만`, `원금과 동일`).
- 입력 중 **실시간 예상 손익과 수익률(%) 미리보기 계산**.
- 실수 방지 삭제 확인 팝업 다이얼로그.

### 7. 사용자 정의 Role 기반 AI 리밸런싱 코칭 (Gemini API)
- 사용자 맞춤형 **aiRole** 페르소나 및 모델(`gemini-1.5-flash`, `gemini-2.0-flash`, `gemini-1.5-pro`) 연동.
- 클릭 한 번으로 현재 포트폴리오 데이터(총자산, 카테고리 비중, 개별 자산 성과, 최근 추이)를 분석하여:
  1. **포트폴리오 리스크 진단** (쏠림 위험, 현금 완충력)
  2. **구체적인 리밸런싱 액션 플랜** (비중 축소/확대 추천, 분할 매매 가이드)
  3. **중단기 포트폴리오 운용 조언**
- 마크다운 파서 기반의 깔끔한 코칭 리포트 카드 UI & 원클릭 복사.

### 8. 환경 설정 (Settings) & 프리셋
- Google AI Studio 무료 API Key 등록 및 비밀번호 마스킹 토글.
- 원클릭 페르소나 프리셋 버튼:
  - `[올웨더/자산배분]`: 올웨더 및 리스크 패리티 전문가 관점
  - `[보수적 가치투자]`: 안전마진과 현금흐름 중심 보수적 가치투자자 관점
  - `[성장/모멘텀]`: 주도주 및 가상자산 트렌드 추종 공격적 수익 극대화 관점

### 9. iOS Safari / 모바일 웹앱 PWA 최적화
- `viewport-fit=cover`, `user-scalable=no` 뷰포트 설정.
- 노치 및 홈 바 여백 대응 (`safe-area-inset-top`, `safe-area-inset-bottom`).
- 모바일 하단 플로팅 자산 등록 버튼 (+) 제공.

## 💻 실행 방법

### 로컬 개발 서버 실행
```bash
npm run dev
```
- PC 로컬 브라우저: `http://localhost:5173`
- 아이폰/동일 네트워크 기기: 터미널에 표시되는 네트워크 주소 (예: `http://192.168.0.7:5173`) 접속
